# 性能测量记录：玻璃渲染（2026-11-20）

原始数据日志，**不是设计约束**。约束见 `design.md` 第 4 节。

四份测量由四个互不通气的 agent 独立完成，各自选择方法；结论不一致处保留原样。

## 条件

| 项 | 值 |
|---|---|
| 渲染 | Radeon 680M 核显，ANGLE OpenGL 4.6 |
| 独显 | RX 6650 XT 处于 vfio，无设备节点，无法 PRIME 切换 |
| 合成 | gamescope `--backend headless`（Xwayland），用户桌面无窗口 |
| 面板 | 2560×1600 @120Hz |
| 采样 | rAF 帧间隔 p50/p95/p99 + >20ms 帧数，部分含 LoAF |
| 隔离 | 测量命令用 `flock` 串行化，前后记录 load average（1.0–2.0） |

## 结果

| 测量 | 视口 / DPR | 像素量 | 对象 | 结果 |
|---|---|---|---|---|
| A | 1707×1067 / 1.5 | ~4.1MP | lab 轻玻璃 | 52–55fps，p50 16.7ms，p95 25.1ms，4s 掉 41–60 帧 |
| B | 1280×800 / 2 | ~4.1MP | lab 全状态 | 53–57fps，p95 25ms；error 状态 47.9fps |
| D | 1707×1067 / 1.5 | ~4.1MP | lab 定案（12px + L3 canvas） | healthy 36.1 / 51.6fps，p95 33.4 / 25.1ms；working 38.1fps，p95 41.6ms，6s 内 >20ms 帧 100–211 |
| D | 1707×1067 / 1.5 | ~4.1MP | 产品现版（55px 整窗模糊 + ambient） | 119.8 / 120.0fps，p95 8.4 / 8.5ms，>20ms 帧 0 |
| B | 1280×800 / 1 | ~1.02MP | lab 同上 | 120fps，p50 8.3ms，p95 8.4ms，0 掉帧（3 次重复） |
| C | 1280×800 / 1 | ~1.02MP | lab 轻/重玻璃 + 产品 Setup | 全部贴 vsync，p50 8.3ms，0 掉帧 |
| A | 1707×1067 / 1.5 | ~4.1MP | 产品预览页 | 115–120fps；关闭 `backdrop-filter` 后回到 120fps |

## 结论

1. 成本随物理像素量走，属 fill-rate 受限；~1MP 下测不出配置差异（2026-11-15 的"性能过剩"是视口太小导致的假阴性）。
2. 同条件下 CSS 55px 整窗模糊跑满 120fps，L3 canvas 方案只有 36–52fps。**贵的是每帧重绘的离屏 canvas 层，不是 CSS 模糊。**
3. 关闭 `backdrop-filter` 只回收 3–5fps，所以降低模糊半径在本机收益很小。
4. 主题切换产生 10 个 >20ms 帧（另一次测量最坏单帧 150ms、主线程长任务 106ms），与视觉方案无关。
5. 真实 Dashboard（55px + StatusGeometry）未测到：无 Tauri 后端、IPC mock 未生效，产品侧数据均来自预览页。

## 有效性

- D 首轮 0 帧：headless 下窗口未被 present，日志 `Render frame was disposed…`，rAF 不回调。加 `--force-windows-fullscreen` 与显式 `--ozone-platform=x11` 后自检通过；仅加 occlusion 三开关无效。
- 主机 17:12–17:28 挂起、17:30–18:43 休眠，跨挂起的 run 一律作废。
- 并发测量负载使帧率波动约 ±10–30%，同配置在不同 run 间可反转。
- 核显冷启动先在约 400MHz 升频，同一配置两轮可差 43%；绝对值按区间读。
- headless 的绝对帧率不等于 niri 实际呈现；rAF 对纯 GPU 合成掉帧存在盲区。

## 历史数据（2026-11-15，不可与本机互推）

环境：Linux + niri、RX 6900 XT、2560×1440@180Hz、DPR 1、Electron 45.3.2、视口 1268×1382（~1.75MP）。

硬件合成，单状态采样 8s：

| 组合 | L3 | 降采样 | L4 | fps | p50 | p95 | dropped |
|---|---|---|---|---|---|---|---|
| 基准 | 36px | 1/4 | 20px | 180.0 | 5.6 | 5.6 | 0 |
| 重玻璃 | 56px | 1/2 | 28px | 180.0 | 5.6 | 5.6 | 0 |
| 性能优先 | 36px | 1/8 | 0px | 180.0 | 5.6 | 5.6 | 0 |
| 极端 | 64px | 1/2 | 32px | 180.0 | 5.6 | 5.6 | 0 |

当时结论为 vsync 上限（p50 = 5.6ms = 180Hz 帧间隔）。该视口约 1.75MP，**正好落在本次被证明为假阴性的区间**，不可外推。

软件渲染（`--software`）对照：

| 组合 | fps | p50 | p95 | dropped |
|---|---|---|---|---|
| 基准 | 17.8 | 50.1 | 100.0 | 177 |
| 关 L4 模糊 | 14.1 | 66.7 | 100.0 | 140 |
| 性能优先 | 14.5 | 66.7 | 94.4 | 144 |

软件合成下整套玻璃不可用。
